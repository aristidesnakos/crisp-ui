**These are the building blocks Real Good Site's tools are made of.** The [training tracker](/tools/training-tracker), for example, is put together from a status strip, a table, a confirm-then-send action and an audit timeline. Copy any one of them into your own project, or let your AI assistant do it.

The pieces follow one order, [See, Decide, Act, Confirm, Record](/docs/story). They are screens only: sending, storage and access control are yours to build, and the [AI guide](/docs/ai) shows how to hand that job to an assistant.

## How it works

- **Open code.** You install the source into your project and own it. There is no package to upgrade.
- **The shadcn CLI.** Items are published as a [shadcn registry](https://ui.shadcn.com/docs/registry), so you install them with the tool you already use.
- **Your theme.** The components use the standard shadcn tokens (`primary`, `muted`, `border`), so they follow whatever theme your project has.
- **Small parts.** Each part works alone, and a composite block wires them together.
