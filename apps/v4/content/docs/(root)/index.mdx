**These are the building blocks Real Good Site's tools are made of.** Each one is a piece of a real tool, such as the [training tracker](/tools/training-tracker), extracted so you or your AI assistant can copy it into your own.

The first pattern is [status and notify](/docs/components/status-notify): a headline that says how a job is going, a confirm-then-send action, and one roster of who hears about it.

## How it works

- **Open code.** You install the source into your project and own it. There is no package to upgrade.
- **The shadcn CLI.** Items are published as a [shadcn registry](https://ui.shadcn.com/docs/registry), so you install them with the tool you already use.
- **Your theme.** The components use the standard shadcn tokens (`primary`, `muted`, `border`), so they follow whatever theme your project has.
- **Small parts.** Each part works alone, and a composite block wires them together.
